# Практична робота №6

## Тема
Створення анімації засобами мови C#.

## Мета роботи
Навчитися створювати графічні об'єкти та реалізовувати їх анімацію засобами мови C# у Windows Forms.

## Завдання
Створити графічне зображення автомобіля та реалізувати його рух по формі.

Побудову графічного об'єкта реалізувати у вигляді функції.

## Виконання роботи
У середовищі Microsoft Visual Studio було створено програму мовою C# з використанням Windows Forms.

У програмі побудовано графічне зображення автомобіля.

Для визначення початкового положення об'єкта використовується змінна координати.

Для створення анімації використовується компонент Timer. Подія Tick забезпечує періодичну зміну координат автомобіля та його переміщення по формі.

Побудова автомобіля реалізована у вигляді окремої функції.

## Використані технології
- C#
- Windows Forms
- Microsoft Visual Studio
- Timer
- Git
- GitHub

## Висновок
Під час виконання практичної роботи №6 було створено графічний об'єкт у вигляді автомобіля та реалізовано його анімацію. Отримано практичні навички роботи з графікою, координатами та компонентом Timer у Windows Forms.
